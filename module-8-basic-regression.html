Lesson 1

Introduction to regression

Regression estimates a response from a set of predictors. The linear version looks for the line — or, with more predictors, the flat surface — whose squared errors add up to as little as possible.

Two kinds of question

Regression

A model that uses a set of factors, called predictors, to estimate a numeric quantity called the response. There are many variations and add-ons; this module covers the basic linear version.

Regression answers two different kinds of question, and it is worth knowing which one you are asking before you fit anything.

Question typeWhat you want out of it
How does the system work?The size of each factor’s effect — how much an extra year of experience is worth in salary, which features matter most in a purchase decision, how strongly an economic indicator moves an outcome.
What will happen?A predicted value for a case you haven’t observed yet — next quarter’s electricity demand, the selling price of a house not yet on the market, the remaining life of a machine part.

Every use shares the same shape: a set of predictors that you know, and a response you are trying to estimate.

Simple linear regression

Simple linear regression

Linear regression with a single predictor. The relationship between predictor and response is assumed to be a straight line.

y = a₀ + a₁x₁One predictor. a₀ is the intercept — the predicted response when x₁ is zero — and a₁ is the slope, the change in predicted response for each one-unit increase in x₁.
y = a₀ + Σⱼ₌₁..ₘ aⱼxⱼm predictors. The picture is no longer a line but a flat surface (a hyperplane) in m + 1 dimensions. Drawings stay two-dimensional only because that is what fits on a page.
Check 2

In y = a₀ + a₁x₁, which symbols are data and which are what the regression finds?

Show answer

x₁ and y come from the data. a₀ and a₁ are the unknowns — the regression coefficients — chosen so the line fits the data as closely as possible.

What “fits best” means

For each data point, the error is the gap between the true response and the model’s estimate. Square each error and add them up; the line with the smallest total is the best fit.

eᵢ = yᵢ − ŷᵢ = yᵢ − (a₀ + a₁xᵢ₁)The error for data point i. yᵢ is the observed response, ŷᵢ (“y-hat”) the regression’s estimate.
SSE = Σᵢ₌₁..ₙ ( yᵢ − (a₀ + Σⱼ aⱼxᵢⱼ) )²The sum of squared errors over all n data points. As the line turns and slides, a₀ and a₁ change and so does this total.
Best-fit regression line

The values of a₀, a₁, …, aₘ that minimise the sum of squared errors. Why squared errors rather than some other measure is the subject of Lesson 2.

How the minimum is found

  1. The sum of squared errors is a convex function of the coefficients — bowl-shaped, with a single lowest point.
  2. Take the partial derivative of the SSE with respect to each coefficient.
  3. Set every partial derivative equal to zero.
  4. Solve those equations simultaneously. The solution is the minimum — the best-fit coefficients.

Check 3

Why is it enough to set the partial derivatives to zero, rather than having to check every candidate line?

Show answer

Because the SSE is convex: it has one minimum and no misleading local dips. Where every partial derivative is zero, the bowl is at its bottom, so solving those equations gives the global best fit directly.

Lesson 2

Likelihood and information criteria

Likelihood measures how well a model fits. AIC and BIC charge it for every parameter it uses, so that extra complexity has to earn its place.

Likelihood

Likelihood

For a given set of parameter values, the probability — strictly, the probability density — of seeing the data we actually observed, under an assumed model of the errors. It is the most basic measure of model quality.

Maximum likelihood

The set of parameters that gives the highest likelihood. That set is the best-fit set of parameters, and the likelihood it reaches is written L*.

Lecture vs standard practice — which way round the probability runs

Lecture: describes likelihood as the probability that the model would generate the estimates it does, treating the observed data as the correct values.

Standard definition: the probability (density) of the observed data given the parameters. The lecture’s worked derivation below uses exactly this form — the probability of observing zᵢ if the true value is yᵢ — so the two agree once the math starts. Learn the standard wording; it is what textbooks and exams use.

Check 4

What is being varied, and what is being held fixed, when you maximise a likelihood?

Show answer

The data are held fixed — they are what was observed. The parameters are varied, and you keep the set that makes the observed data most probable.

Why least squares is maximum likelihood

Assume the errors are normally distributed with mean 0 and variance σ², and independent from one data point to the next. Let z₁ … zₙ be the observed values and y₁ … yₙ the model’s estimates.

P(zᵢ | yᵢ) = ( 1 / (σ√(2π)) ) · exp( −(zᵢ − yᵢ)² / (2σ²) )Probability density of observing zᵢ if the true value is yᵢ.
L = Πᵢ P(zᵢ | yᵢ) = ( 1 / (σ√(2π)) )ⁿ · exp( −(1/(2σ²)) · Σᵢ (zᵢ − yᵢ)² )Independent errors, so the joint probability is the product — which collapses into a single exponential.

The exponential gets larger as its exponent gets larger, so maximising L means maximising the exponent. Strip the constants and what’s left is minus the sum of squared errors. Maximising that is the same as minimising the SSE.

maximise L  ⇔  minimise Σᵢ ( zᵢ − (a₀ + Σⱼ aⱼxᵢⱼ) )²Substituting the regression estimate for yᵢ. With independent, identically distributed normal errors, least squares is the maximum likelihood fit.
put in ordersolved

Put the steps of the argument that least squares is maximum likelihood in order. Drag, or use the arrows.

  1. Assume errors are normal with mean 0 and variance σ², independent across data points
  2. Write the normal density of observing each zᵢ when the true value is yᵢ
  3. Multiply the n densities together, because the errors are independent
  4. Combine the product into one exponential, and note that it is largest when its exponent is largest
  5. Drop the constants, leaving the negative sum of squared errors
  6. Conclude that minimising the sum of squared errors gives the maximum likelihood parameters

Likelihood can also compare two models directly: take the likelihood ratio and run a hypothesis test on it. The conditions that test needs are in Extra 2.

Beyond simple regression — other estimating formulas, other error assumptions — maximum likelihood gets complex and may not have an easy solution. Good statistical software handles much of that for you.

Check 5

Which two assumptions about the errors make least squares equivalent to maximum likelihood?

Show answer

They are normally distributed (with mean 0 and a common variance), and they are independent of one another — together, independent and identically distributed normal errors.

Drop either one and minimising the SSE is no longer guaranteed to be the maximum likelihood fit.

Trading fit against complexity: AIC

Adding parameters can always improve the fit — but it can also lead to overfitting, where the extra parameters fit random effects rather than real ones. The information criteria balance the two.

AIC = 2k − 2 ln(L*)Akaike information criterion. L* is the maximum likelihood value, k the number of parameters being estimated. 2k is the penalty term. Smaller AIC is preferred.
AIC = n · ln( SSE / n ) + 2k  (+ a constant)The regression version, with normal errors substituted into the likelihood. The constant is the same for every model fitted to the same data, so it never changes which model wins.

Making AIC smaller pushes two ways at once: toward higher likelihood and toward fewer parameters. The underlying math comes from information theory.

AICc = AIC + 2k(k + 1) / (n − k − 1)Corrected AIC. AIC’s nice properties hold as the number of data points goes to infinity; the correction term handles the ordinary case of a finite dataset. It shrinks toward zero as n grows.

Lecture vs standard practice — how many parameters k counts

Lecture: for regression, k = m + 1 — one for each coefficient a₀ … aₘ.

Common software practice: the error variance σ² is also estimated, so many packages (R’s AIC() on a linear model, for example) count k = m + 2. Every model on the same data gets the same extra 1, so AIC differences — the only thing you compare — come out the same either way. Just don’t compare a hand-computed AIC to a software-reported one.

Check 6

Adding a parameter raises ln(L*) by 0.6. Does AIC go up or down?

Show answer

Up. The penalty rises by 2, and the fit term falls by 2 × 0.6 = 1.2, a net increase of 0.8. The parameter improved the fit, but not by enough to pay for itself.

Under AIC, an extra parameter has to raise ln(L*) by more than 1 to be worth keeping.

Comparing two AIC values

The gap between two models’ AIC values converts into a relative probability that one is better than the other.

relative likelihood = exp( (AIClow − AIChigh) / 2 )How likely the higher-AIC model is to be the better one, relative to the lower-AIC model.

Example: two models differ by 4 in AIC. exp(−4/2) = e−2 ≈ 0.135, so the higher-AIC model is about 13.5% as likely as the lower-AIC one to be the better model.

Lecture vs standard practice — the exponent

The recording’s spoken version of this formula comes through garbled in the transcript. Its own worked number, though — a 5-point AIC gap giving a relative likelihood of 8.2% — is exactly e−2.5, which is the standard formula above with the difference halved. Learn it as exp(−ΔAIC / 2).

Model A has AIC 318; model B has AIC 324. Roughly how likely is B, relative to A, to be the better model?

Check 7

Why can you compare AIC values between two models on the same data, but not between two models fitted to different datasets?

Show answer

The likelihood depends on the data. A different dataset — more points, different values — changes ln(L*) for reasons that have nothing to do with the model, so the AIC gap no longer measures which model is better.

BIC: a heavier penalty

BIC = k · ln(n) − 2 ln(L*)Bayesian information criterion. Same structure as AIC, but the penalty per parameter is ln(n) rather than 2. Smaller is preferred.

Because ln(n) exceeds 2 once n is 8 or more, BIC’s penalty is generally larger than AIC’s, and it tends to favour models with fewer parameters.

BIC differenceSmaller-BIC model is …
more than 10very likely better
6 to 10likely better
2 to 6somewhat likely better
0 to 2only slightly likely better

That table is a rule of thumb. It is an inexact science, and there is no hard-and-fast rule for choosing between AIC, BIC or plain maximum likelihood. For readers with a statistics background, AIC comes from a frequentist point of view and BIC from a Bayesian one. All three give valuable information, and looking at them together helps you choose among the models you are testing.

Lecture vs standard practice — when BIC “breaks down”

Lecture: BIC breaks down as the number of data points gets close to the number of parameters, so only use it when you have a lot more data than parameters.

Standard view: the advice is right — BIC’s justification is a large-sample approximation, so it is unreliable when n is not much bigger than k. But the formula itself doesn’t misbehave there; the criterion whose formula literally blows up as n approaches k + 1 is AICc, through its n − k − 1 denominator. Both point to the same practical rule: with few data points per parameter, trust none of these numbers very far.

Lesson 3

Using regression

For questions about how a system works, the coefficients are the answer. For forecasts, the predicted responses are. The same fitted equation serves both.

Notation

SymbolMeaning
nNumber of data points
mNumber of predictors
yᵢResponse of the i-th data point
xᵢⱼValue of the j-th predictor for data point i
a₀The constant (intercept)
a₁ … aₘThe coefficients, one per predictor, chosen so the model best fits the data
ŷᵢ = a₀ + a₁xᵢ₁ + a₂xᵢ₂ + … + aₘxᵢₘThe fitted equation. Every use of regression in this lesson reads something off it.
Check 9

In xᵢⱼ, which index runs over data points and which over predictors?

Show answer

i runs over data points (1 to n); j runs over predictors (1 to m). So x₄₂ is the second predictor’s value for the fourth data point.

Describing how a system works: read the coefficients

Suppose a retailer compiles, for many store-weeks, the number of units sold (the response) and predictors such as price, advertising spend, number of promotions running and whether the week contained a holiday. After fitting, there is one coefficient per predictor.

Each coefficient says how much the predicted response changes when that predictor goes up by one unit, with the others unchanged. If the advertising coefficient comes out at 40 with spend measured in thousands of dollars, then every extra thousand dollars of advertising is associated with about 40 more units sold, on average.

Coefficient aⱼ (descriptive reading)

The change in the predicted response for a one-unit increase in predictor j, holding the other predictors fixed. Its units are “response units per predictor unit”.

quick checkanswered

A regression of monthly electricity use (kWh) on floor area (square metres) and occupants gives a floor-area coefficient of 0.8. What does 0.8 mean?

Check 10

Why does “holding the other predictors fixed” matter when you read a coefficient?

Show answer

Because each coefficient is estimated alongside the others. The advertising coefficient answers “what if spend rises and price, promotions and holidays stay as they were?” — which can differ a lot from what happens when advertising tends to rise together with promotions.

That caution is also the bridge to Lesson 4: a coefficient describes an association, not automatically a cause.

Predicting what will happen: read the responses

Suppose instead you want to predict the selling price of a used car. Compile data on many past sales: the response is the sale price, and the predictors might be age, mileage, engine size and a condition rating. Fit the model and you again have one coefficient per predictor.

Now take a new car that hasn’t sold. You know its predictors but not its response. Plug the predictors into the fitted equation and the output ŷ is the predicted selling price. Here the coefficients are only the means to an end; the number you act on is the prediction.

Descriptive, predictive and prescriptive analytics: which does regression cover directly, and why is it so widely used?

Show answer

It covers descriptive (via the coefficients) and predictive (via the fitted responses) — two of the three. Only prescriptive questions fall outside it, which is why regression is one of the most commonly used tools in analytics.

Lesson 4

Causation vs. correlation

A regression that predicts well shows that two things move together. Whether one drives the other is a separate question that the fit itself cannot settle.

The two words

Causation

One thing causes another.

Correlation

Two things tend to happen, or not happen, together — but neither of them need cause the other.

Run the regression backwards

Take a dataset of daily rainfall and umbrella sales across many towns. Regress umbrella sales on rainfall and the coefficient is strongly significant: wetter days sell more umbrellas. Saying “because it rained, people bought umbrellas” is reasonable.

Now swap the roles. Regress rainfall on umbrella sales, using the same data. The p-value and the model’s quality measures come out exactly the same. Does that show that buying umbrellas makes it rain? Obviously not — yet the model is just as good at prediction: tell me one town sold far more umbrellas than another today and I can predict it was the wetter one.

y = a₀ + a₁x₁   and   x₁ = b₀ + b₁yBoth directions of a simple regression on the same data have identical p-values and fit quality. The model’s statistics cannot tell you which way the arrow points.
Check 12

If a regression’s quality metrics are identical in both directions, what information must decide which direction is causal?

Show answer

Knowledge from outside the model — which came first, whether a mechanism makes sense, and whether some other factor could be driving both. The data alone, fitted this way, is symmetric.

The third factor

Sometimes neither variable causes the other, and both are driven by something else. Weekly ice-cream sales and weekly drownings rise and fall together; a regression would predict one from the other quite well. Neither causes the other: hot weather sends more people to buy ice cream and more people into the water.

Outside factor (confounder)

A factor that influences both the predictor and the response, producing a correlation between them even when there is no causal link between the two.

Check 13

Why is “no outside factor” the hardest of the causal rules of thumb to satisfy?

Show answer

Because it requires thinking of every possible external factor, and no one can do that with certainty. The other two — cause before effect, and the idea making sense — can be checked directly.

So when can you claim causation?

There is a fair amount of philosophical thought on this, including the view that proving causation is theoretically impossible. Fortunately absolute proof isn’t needed. People draw causal conclusions from rules of thumb all the time and are often right. Most rules of thumb boil down to three conditions:

  1. The cause comes before the effect.
  2. The idea of causation makes sense. There is a plausible mechanism.
  3. No outside factor could be causing the relationship. The hardest to ensure.

Randomised experiments and controls help with the third condition, but you may still miss something — which is why so many studies, especially of human behaviour, are controversial. It is usually not hard to find a possible outside factor that might be part of the cause.

None of this means models can’t suggest causation. Coming up with insightful causal relationships is an important part of analytics. It means being careful, and thinking through every possibility you can, before claiming that a model shows causation.

Lesson 5

Transformations and interactions

“Linear” regression only has to be linear in its coefficients. Squares, logs and products of the attributes all go in as new columns of data, and the fitting works exactly as before.

When the data isn’t a straight line

In the basic formula each attribute appears linearly: its value xⱼ is multiplied by a coefficient aⱼ. That works when the data looks linear. When it curves, a straight line fits badly, and a curve fits much closer.

So transform the data to make the fit linear. If the data looks like y = x², include a quadratic term. Doing so simply creates a new column of data, x₁², and the regression treats it like any other attribute.

y = a₀ + a₁x₁ + a₂x₁²Still linear regression: the equation is linear in a₀, a₁ and a₂, even though it is curved in x₁.

Any other function of the attributes can be used the same way, if it fits the data — a log, a square root, a reciprocal.

Check 15

Why is y = a₀ + a₁x₁ + a₂x₁² still “linear” regression?

Show answer

“Linear” refers to the coefficients, not the attributes. x₁² is just another column of numbers; the response is still a₀ plus a sum of coefficients times columns, so the same least-squares fitting applies unchanged.

Transforming the response

The response can be transformed too — for example, regress the log of the response instead of the response itself — or both the attributes and the response can be transformed together.

Box-Cox transformation

A family of power transformations of the response, indexed by a single parameter λ, that most statistical software can choose automatically.

y(λ) = (yλ − 1) / λ   for λ ≠ 0 ,    y(0) = ln yThe standard Box-Cox form (the lecture names the method without writing it out). λ = 1 leaves the shape unchanged, λ = 0.5 is a square-root transform, λ = 0 a log. It needs y > 0.
quick checkanswered

Plotting delivery cost against distance, the points rise steeply at first and then level off. Which change to the model is the natural first try?

Check 16

Name three things you can transform in a regression.

Show answer

An attribute (for example, add x² or use ln x); the response (for example, regress ln y); or both at once. Box-Cox is a family of response transformations that software can fit for you.

Interactions

Sometimes attributes interact. Take crop yield as a function of irrigation and fertiliser. Yield may depend on each separately, and also on their product: fertiliser may help far more on a well-watered field than on a dry one. The individual terms alone can’t capture that; an interaction term can.

y = a₀ + a₁x₁ + a₂x₂ + a₃(x₁x₂)The interaction term x₁x₂ becomes a new column of data and is treated like any other attribute. It can be transformed too.
Interaction term

A term built from two or more attributes together — typically their product — that lets the effect of one attribute depend on the value of another.

Once transformations and interaction terms are included as columns, software finds the best-fit coefficients in exactly the same way as before.

quick checkanswered

In y = a₀ + a₁x₁ + a₂x₂ + a₃x₁x₂, by how much does the predicted y change when x₁ rises by one unit?

put in ordersolved

Put the steps for adding a transformed term to a regression in order.

  1. Plot the response against the attribute and see that the relationship curves
  2. Choose a function of the attribute that matches the shape — a square, a log, a product with another attribute
  3. Compute that function for every data point, creating a new column
  4. Refit the regression with the new column included like any other attribute
  5. Compare the new model with the old one — for instance on AIC or BIC — before keeping the term

Lesson 6

Reading regression output

Fitting is not the end. The output tells you which attributes are really significant, whether they matter in practice, and how much of the variation the model accounts for — if you know how far to trust each number.

What a standard output looks like

A delivery firm regresses delivery time in minutes on trip distance, number of stops and a weekend indicator, using 100 past deliveries. The printed summary looks like the one below; every package lays it out in roughly this way.

Check 18

Four numbers on each coefficient row carry overlapping information. Which three are really the same test?

Show answer

The p-value, the t-statistic (coefficient ÷ standard error) and the 95% confidence interval. All three ask how far the estimate sits from zero relative to its uncertainty.

The estimate itself answers a different question: how big the effect is.

p-values

p-value (of a coefficient)

The result of a hypothesis test on whether the coefficient could really be zero. Small p-values say the attribute very probably matters; large ones say the data are consistent with no effect.

The common rule of thumb: if a coefficient’s p-value is greater than 0.05, remove that attribute from the model. Other thresholds can be used, depending on how conservative you want to be:

ThresholdEffect
higher (e.g. 0.10)More attributes kept; more likely an irrelevant one ends up in the model.
lower (e.g. 0.01)Fewer attributes kept; more risk of leaving out a relevant one.

For most attributes the decision isn’t close. p-values tend to be very low — 0.001 or less, so the attribute is almost certainly important — or very high, 0.3 or more.

Lecture vs standard practice — what a p-value is

Lecture: the p-value estimates the probability that the coefficient really might be zero.

Standard definition: assuming the true coefficient is zero, the p-value is the probability of getting an estimate at least as far from zero as the one observed. It is a statement about the data given “no effect”, not the probability that “no effect” is true. The practical rule — small p means keep, large p means doubtful — is the same under either reading, but on a written exam, give the standard one.

t = aⱼ / SE(aⱼ)   ·   95% CI ≈ aⱼ ± 2·SE(aⱼ)The t-statistic and the approximate 95% confidence interval, both built from the estimate and its standard error. (The exact multiplier comes from the t distribution and is about 1.96–2 for moderately large samples.)
Check 19

Lowering the p-value threshold from 0.05 to 0.01: which mistake becomes more likely, and which less?

Show answer

Keeping an irrelevant attribute becomes less likely; leaving out a relevant one becomes more likely. A threshold trades one error against the other.

Two warnings about p-values

1 · With a great deal of data, p-values get small. They can become tiny even for attributes that have no meaningful relationship to the response, so with very large datasets be careful about relying on them.

2 · They are only probabilities, so some will be wrong. Test many attributes and some that look significant will not be. If you run a hundred tests on attributes that truly have no effect, a 0.02 threshold will let about two of them through by chance. When the findings are acted on — people change what they eat, what they buy, what they prescribe — those false positives have real consequences.

Lecture vs standard practice — the two warnings, stated exactly

Large data. The lecture says p-values shrink even when an attribute is “not at all related” to the response. Strictly, if the true effect is exactly zero, p-values do not drift toward zero as data grows. What large samples do is make a tiny but non-zero effect highly significant — statistically real, practically meaningless. The lecture’s advice (don’t lean on p-values with huge data; look at effect size) is standard.

Many tests. The lecture frames it as “each attribute with p = 0.02 has a 2% chance of not being significant, so about two in a hundred are irrelevant.” The standard framing: 2% is the false-positive rate among attributes whose true effect is zero, so the expected number of spurious findings depends on how many of the tested attributes are truly null. The conclusion — test many things and some “discoveries” will be noise — is exactly the standard multiple-comparisons problem. Corrections for it are in Extra 2.

quick checkanswered

A model of household water use, fitted on 3 million homes, gives a coefficient for “house painted light colour” of 0.02 litres per day, p < 0.0001. What should you conclude?

Check 20

Why can the number of attributes you test turn a sound analysis into a misleading one?

Show answer

Each test has some chance of a false positive. Across many tests those chances add up, so a list of “significant” attributes will contain some that are pure noise — and you can’t tell from the p-values which ones.

Look at the coefficient itself

Even with a very low p-value, a coefficient multiplied by a realistic range of its attribute may make almost no difference. Suppose a model of house sale prices, in the hundreds of thousands of dollars, gives a coefficient of $15 per electrical outlet. Across the realistic range — say 10 to 40 outlets — that moves the prediction by under $500. Not meaningful at that scale, however small its p-value.

Practical significance

Whether an effect is large enough to matter, judged by coefficient × a realistic change in the attribute, compared with the size of the response. Distinct from statistical significance, which is what the p-value measures.

How much the model explains: R²

R² (coefficient of determination)

An estimate of how much of the variability in the response the model accounts for. R² = 0.59 means about 59% is accounted for; the remaining 41% is randomness or factors the model doesn’t capture.

Adjusted R²

R² adjusted for the number of attributes used. Plain R² can only rise when attributes are added; the adjusted version can fall if an attribute doesn’t pull its weight.

R² = 1 − SSE / SST ,    SST = Σᵢ (yᵢ − ȳ)²Standard definition: one minus the unexplained share of the total variation around the mean.
adjusted R² = 1 − (1 − R²) · (n − 1) / (n − m − 1)n data points, m attributes. The factor (n − 1)/(n − m − 1) grows with m, so extra attributes are charged for.

Keep expectations realistic. Textbook exercises often come with clean datasets and R² of 90% or more; real systems rarely allow that, because so much affects them. Where humans are involved — social science, behavioural analytics — R² of 0.3 or 0.4 can be quite good.

Exam target

Across a hospital’s patients, length of stay rises strongly with the number of prescriptions written, p < 0.001. An administrator proposes capping prescriptions to shorten stays. What is wrong with the reasoning?

Show answer

It reads a correlation as a cause. Severity of illness is an obvious outside factor: sicker patients both stay longer and receive more prescriptions. The arrow may also partly run the other way — a longer stay gives more occasions to prescribe. A small p-value says the association is unlikely to be chance; it says nothing about which of these stories is true. Capping prescriptions could lengthen stays.

Exam target

Plant growth rises with watering up to a point and falls when plants are overwatered. A straight-line regression of growth on water gives a slope of nearly zero, p = 0.6. Is watering irrelevant?

Show answer

No. The relationship is strong but curved: the rising and falling halves cancel in a straight-line fit, so the linear coefficient is near zero. Add a squared term (water²) as a new column. Expect a positive coefficient on water and a negative one on water², giving a hump; the p-values and fit should change dramatically. A large p-value on a linear term means “no linear relationship”, not “no relationship”.

Exam target

Two models of server response time, fitted to the same logs, have AIC 1,204 and 1,210. How much more likely is the first to be the better model?

Show answer

exp((1,204 − 1,210)/2) = e−3 ≈ 0.05. The second model is about 5% as likely as the first to be the better one — equivalently, the first is about twenty times as likely. Only the difference matters; the size of the AIC values themselves carries no meaning.

Exam target

A startup has 12 months of revenue data and a model with 9 parameters. Which of AIC, AICc and BIC would you trust to compare it with a 3-parameter model?

Show answer

AICc is the appropriate one of the three, and it will be damning: its correction 2k(k+1)/(n−k−1) is 2·9·10/2 = 90 for the large model, against 2·3·4/8 = 3 for the small one. Plain AIC assumes plenty of data and BIC is a large-sample approximation, so neither is reliable here. The deeper point: 12 observations cannot support 9 parameters at all, and the large model is almost certainly fitting random effects.

Exam target

A price model for 45 wines uses 40 descriptive attributes and reports R² = 0.96. Adjusted R² is 0.56. Explain the gap.

Show answer

With 40 attributes and only 45 data points, the model has almost one coefficient per observation, so it can follow the data — including its randomness — nearly perfectly. R² can only rise as attributes are added. Adjusted R² = 1 − (1 − 0.96)·44/4 = 0.56 charges for each one. The gap is the signature of overfitting; the 0.96 will not survive new wines.

Exam target

A study tests 200 genetic markers for association with a condition, one regression each, at the 0.05 level. Fourteen come out significant. How excited should anyone be?

Show answer

Not very. If none of the 200 markers had any real association, about 200 × 0.05 = 10 would still pass by chance. Fourteen is only modestly more than that, so most of the list may be noise, and the p-values can’t say which entries are real. A multiple-testing correction (Extra 2) or an independent replication is needed before acting on any of them.

Exam target

An online shop fits spend = a₀ + a₁·discount + a₂·member + a₃·(discount × member), where member is 1 for loyalty-scheme members and 0 otherwise. The fit gives a₁ = 3 and a₃ = 4. What does each extra unit of discount do?

Show answer

For non-members (member = 0) the discount effect is a₁ = 3 per unit. For members it is a₁ + a₃ = 7 per unit. The interaction term lets the discount’s effect differ between the two groups; without it, the model would force one common slope and report something in between that is right for neither.

The through-line across all six lessons

  • Lesson 2Justifies that criterion — least squares is maximum likelihood under normal, independent errors — and adds AIC and BIC to charge for complexity.
  • Lesson 3Puts the fitted equation to work: coefficients answer how a system works, predictions answer what will happen.
  • Lesson 4Limits what the coefficients can claim. A good fit shows correlation; causation needs time order, sense, and no outside factor.
  • Lesson 5Widens the model: squares, logs, Box-Cox and products go in as new columns, and the same fitting applies.
  • Lesson 6Reads the result: p-values, intervals, t-statistics and coefficient sizes for each attribute; R² and adjusted R² for the whole model.

Four things worth noticing

  • Complexity is charged three times over. AIC and BIC in Lesson 2, adjusted R² in Lesson 6, and the p-value threshold in Lesson 6 all exist to stop a model keeping parameters that only fit noise.
  • Every quality number is symmetric about direction. Lesson 4’s reverse regression has the same p-value and R² as the forward one — none of Lesson 6’s output can tell you which way cause runs.
  • “Linear” is about coefficients. Lesson 5’s transformations are why a method that draws straight lines can still fit curves and interactions.
  • Significance and importance are different questions. A p-value asks whether an effect might be zero; the coefficient times a realistic change asks whether it matters. Large datasets pull the two apart.

Extra 1 · not class material

What least squares assumes, and how to check it

The coefficients come out whatever the data look like. Whether the p-values, intervals and R² mean what Lesson 6 says depends on assumptions you can check in the residuals.

The assumptions, and what breaks without each

AssumptionWhat fails if it doesn’t hold
LinearityThe mean response really is a₀ + Σaⱼxⱼ (after any transformations). If not, coefficients describe the wrong shape and predictions are biased in systematic places.
IndependenceErrors don’t influence one another. Time-ordered or clustered data (repeat customers, the same patient measured weekly) break this, and standard errors come out too small — p-values too optimistic.
Constant varianceErrors have the same spread everywhere (homoscedasticity). A fan shape — spread growing with the fitted value — also makes the standard errors wrong.
Normal errorsNeeded for exact p-values and intervals in small samples, and for Lesson 2’s maximum-likelihood argument. With large n the coefficient tests are fairly robust to non-normality; prediction intervals are not.
No perfect collinearityNo predictor is an exact combination of others. If one is, the coefficients can’t be separated at all; if nearly so, they become unstable.

The one plot to always make

Plot residuals against fitted values. What you want is a shapeless horizontal band around zero. A curve means a missing transformation (Lesson 5); a fan means non-constant variance, often fixed by logging the response; a few far-off points are candidates for Module 5’s outlier questions. A normal Q–Q plot of the residuals checks the normality assumption.

quick checkanswered

A residuals-versus-fitted plot shows residuals tightly packed for small fitted values and widely spread for large ones. What is the usual first move?

Worth noticing

Which assumptions affect the coefficients themselves, and which only the uncertainty around them?

Show answer

Linearity affects the coefficients: fit the wrong shape and they are wrong. Independence, constant variance and normality mainly affect the standard errors — and so the p-values and intervals — while leaving the least-squares estimates themselves unbiased.

The closed-form solution

Lesson 1 sets the partial derivatives of the SSE to zero and solves. Written in matrices, with X the n × (m+1) data matrix whose first column is all ones, the solution is

â = (XᵀX)⁻¹ XᵀyThe normal equations. Software rarely inverts XᵀX directly — it uses a QR decomposition for numerical stability — but the answer is the same.
a₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)² ,    a₀ = ȳ − a₁x̄The one-predictor case. The fitted line always passes through the point of means (x̄, ȳ).

Influence, collinearity and categories

Leverage and Cook’s distance

Leverage measures how unusual a point’s predictor values are; Cook’s distance measures how much the fitted coefficients change when the point is removed. A point with high leverage and a large residual can move the whole line. Common flags are Cook’s D above 4/n (screening) or above 1 (serious).

Variance inflation factor (VIF)

VIFⱼ = 1 / (1 − R²ⱼ), where R²ⱼ comes from regressing predictor j on all the other predictors. It says how much collinearity inflates that coefficient’s variance. Rules of thumb treat values above 5 or 10 as a problem.

Dummy (indicator) variables

A categorical predictor with c levels enters as c − 1 columns of 0/1, one level left out as the reference. Each coefficient is that level’s difference from the reference. Including all c columns alongside the intercept is perfect collinearity.

The hierarchy principle

If an interaction x₁x₂ or a power x₁² is in the model, keep the main effect x₁ (and x₂) too, even if its own p-value is large. Removing it forces the effect through zero at an arbitrary point. Centering predictors before forming products makes the main effects interpretable and reduces collinearity with the product.

Worth noticing

Why can collinearity leave predictions fine while ruining interpretation?

Show answer

Prediction needs only the combined effect of the correlated predictors, which is estimated well. Interpretation needs each one’s separate effect, which the data can’t pin down. Lesson 3’s two uses of regression react very differently to the same problem.

Inference done carefully

What a p-value can and can’t say, how to correct for testing many things, which interval to report, and when a likelihood ratio test is valid.

What p-values are not

The American Statistical Association’s 2016 statement on p-values (Wasserstein & Lazar) sets out the standard cautions. A p-value is not the probability that the null hypothesis is true; it does not measure the size or importance of an effect; and a scientific conclusion should not rest on whether it crosses a threshold. Report estimates and intervals alongside it.

Multiple testing

Bonferroni: test each of M hypotheses at α / MControls the chance of even one false positive across the whole family. Simple and very conservative.
Benjamini–Hochberg: sort p₍₁₎ ≤ … ≤ p₍M₎ ; find the largest k with p₍k₎ ≤ (k/M)·q ; reject hypotheses 1 … kControls the false discovery rate — the expected share of false positives among the discoveries — at q. Much less conservative when many effects are real.

Stepwise selection and p-values

Lesson 6’s rule of thumb — drop attributes with p > 0.05 — is sometimes automated as backward elimination. Two standard cautions. Removing one attribute changes the others’ p-values, especially under collinearity, so drop one at a time and refit. And the p-values of the final model no longer mean what they claim, because the model was chosen by looking at them. Validation on held-out data (Module 3) or penalised methods such as the lasso are the usual alternatives.

quick checkanswered

You test 50 predictors and want at most a 5% chance of any false positive across all of them. What threshold does Bonferroni give each test?

Worth noticing

When would you prefer Benjamini–Hochberg to Bonferroni?

Show answer

When testing many hypotheses as a screen, where some false leads are acceptable as long as most discoveries are real — gene screens, feature screening. Bonferroni suits a small number of tests where any single false positive is costly.

Confidence interval vs prediction interval

Around a predicted value there are two intervals. The confidence interval covers the average response at those predictor values; it narrows as n grows. The prediction interval covers a single new observation, so it adds the error variance σ² and never shrinks below it however much data you have. For a forecast of one case — one house, one delivery — the prediction interval is the honest one.

The likelihood ratio test

LR = 2 · ( ln L*big − ln L*small )  ~  χ² with (kbig − ksmall) degrees of freedomValid when the smaller model is nested in the bigger one — obtainable by setting some of its parameters to zero — and the sample is reasonably large. Non-nested models are compared with AIC or BIC instead.

Two facts about direction and scale

Reverse regression is not the inverse line. In Lesson 4’s swap, the two slopes satisfy a₁ · b₁ = r², the squared correlation. Unless the fit is perfect, b₁ is not 1/a₁: each regression pulls toward its own mean.

Reading logged models. With ln y as the response, a coefficient a means each unit of x multiplies y by eᵃ — roughly a 100·a% change when a is small. With both sides logged, the coefficient is an elasticity: a 1% change in x goes with about an a% change in y.

Worth noticing

Why does a prediction interval never collapse to zero width, even with unlimited data?

Show answer

More data pins down the line — the average — ever more precisely. But a single new case still scatters around that line with the error variance σ², and no amount of data removes that. The interval’s floor is the irreducible noise.

Part A — fitting and reading

Problem 1 — a fit by hand

Data: x = 1, 2, 3, 4, 5 and y = 3, 5, 4, 8, 10. Find the least-squares line, the SSE and R².

Show worked solution

x̄ = 3, ȳ = 6. Σ(x − x̄)(y − ȳ) = 6 + 1 + 0 + 2 + 8 = 17; Σ(x − x̄)² = 10.
a₁ = 17 / 10 = 1.7; a₀ = 6 − 1.7·3 = 0.9.
Fitted: 2.6, 4.3, 6.0, 7.7, 9.4. Residuals: 0.4, 0.7, −2.0, 0.3, 0.6 — they sum to zero, as least-squares residuals with an intercept always do.
SSE = 0.16 + 0.49 + 4 + 0.09 + 0.36 = 5.1. SST = 9 + 1 + 4 + 4 + 16 = 34.
R² = 1 − 5.1/34 = 0.85. Adjusted R² = 1 − 0.15·4/3 = 0.80.

Problem 2 — a coefficient row

An estimate is 1.8 with standard error 0.6, on a large sample. Give t, an approximate 95% interval, and whether p is above or below 0.05.

Show worked solution

t = 1.8 / 0.6 = 3.0. Interval ≈ 1.8 ± 2·0.6 = 0.6 to 3.0. Zero is outside it, so p is below 0.05 (about 0.003). All three say the same thing, which is the point of Check 18.

Part B — choosing between models

Problem 3 — AIC, AICc and BIC disagreeing

On n = 50 points, model A has k = 3 and SSE = 400; model B has k = 5 and SSE = 340. Using AIC = n·ln(SSE/n) + 2k and the analogous forms, compare them.

Show worked solution

AIC: A = 50·ln 8 + 6 = 109.97; B = 50·ln 6.8 + 10 = 105.85. B lower by 4.12; A is exp(−2.06) ≈ 13% as likely to be better.
AICc: add 2k(k+1)/(n−k−1): A + 0.52 = 110.49; B + 1.36 = 107.21. B still lower by 3.3.
BIC: replace 2k with k·ln 50 = 3.91k: A = 115.71; B = 115.41. B lower by only 0.30 — “only slightly likely” better on the rule-of-thumb table.

The heavier BIC penalty nearly cancels the fit improvement. Report that the two extra parameters help modestly, and check on validation data before committing.

Problem 4 — how many false positives?

A team screens 200 candidate predictors, one test each at α = 0.05, and finds 14 significant. (a) How many would you expect by chance if none mattered? (b) What is the Bonferroni per-test threshold?

Show worked solution

(a) 200 × 0.05 = 10. Fourteen is barely above chance. (b) 0.05 / 200 = 0.00025. Only predictors clearing that bar would be reported under family-wise control; Benjamini–Hochberg would be the less strict alternative for a screen.

Part C — transformations and interactions

Problem 5 — an interaction with a 0/1 variable

y = 20 + 3d + 5m + 4dm, where m is 1 for members. Give the intercept and slope in d for each group.

Show worked solution

Non-members (m = 0): y = 20 + 3d — intercept 20, slope 3.
Members (m = 1): y = 25 + 7d — intercept 20 + 5, slope 3 + 4.
A 0/1 interaction is exactly “a separate line per group”, fitted in one model.

Problem 6 — a logged response

ln(y) = 2.1 + 0.03x. By how much does a one-unit increase in x change y?

Show worked solution

It multiplies y by e0.03 ≈ 1.0305, a 3.05% increase — close to the 3% shortcut because 0.03 is small. The absolute change depends on where you start; the percentage doesn’t.
