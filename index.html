ISyE 6501 study guide

Lecture transcripts turned into something you can actually revise from — one page per module, with activities that tell you straight away whether you understood it.

    Answers and typed notes are stored in this browser and shared across every module page. Use Export to back them up or move them to another machine — some browsers block storage for files opened straight from disk, and Export always works either way.

    Adding a module

    Two steps

    1. Add one line to study.js. The list at the very top of that file is the single source of truth — the tab bar on every page and the cards above both build themselves from it.

    { id:"m5", file:"module-5-something.html", tab:"Module 5 — Title",
  title:"Title", colour:"#8a5a1c", blurb:"One line about the module." }

    2. Copy module-template.html to the filename you just used, set <body data-page="m5">, and fill in the lessons. The template contains a commented example of every block type.

    Blocks you can use inside a lesson

    BlockWhat it is
    .keylineThe one-sentence takeaway under a lesson title
    .defnA term worth memorising, with an accent bar
    .calloutA bordered aside for caveats and warnings
    .formulaMonospace maths with an optional caption
    .stepsNumbered procedure with circled numerals
    aside.checkMargin question with a collapsed answer
    .noteEditable class-discussion box

    Interactive blocks

    AttributeWhat it does
    data-quizMultiple choice with instant feedback on every option, right or wrong
    data-orderDrag rows into sequence; arrow buttons give a keyboard route
    data-matchClick a term, then its pair; the right column shuffles on load
    data-hotspotClickable regions on an SVG that fill a panel underneath
    data-branchBranching scenario — each choice shows its consequence

    Every one of these needs a unique id starting with the module id, like data-quiz="m5l2-q1". That prefix is how progress gets counted per module. Give each lesson <section class="lesson" data-short="…"> so the progress rail has a label, and update MODULE_ITEM_COUNTS in index.html with the number of interactive blocks the module contains.
